# One-time GitHub setup

Create an empty GitHub repository named `AMERICAN_PLATFORM`, then run from `D:\\AMERICAN_PLATFORM`:

```powershell
git init
git branch -M main
git add .
git commit -m "Initialize official American Platform from SAT Engine V4"
git remote add origin https://github.com/YOUR_USERNAME/AMERICAN_PLATFORM.git
git push -u origin main
```

For future work, edit this same folder only. Do not create numbered project copies.
